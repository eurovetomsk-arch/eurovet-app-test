## Отклонения, видимые на 375 px

- В текущем кандидате часть шапки, нижней навигации, денежных значений и длинных строк выходит вправо за viewport. Это зафиксировано как есть и в снимках не исправлялось.
- Содержимое блока авансов взято из 1.90; внешний вид — из текущего кандидата 2.0.
- Разделы без принятого макета — график, касса/сейф, смены и экраны руководителя — не переоформлялись и остаются в прежнем виде; отдельные снимки редизайна для них не создавались.
- Для кадров отдельных секций использован локальный снимочный стенд, который изолировал уже отрисованные DOM-блоки в viewport; разметка и стили самих блоков не менялись.
