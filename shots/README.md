## Матрица адаптивности

Каждый из 11 экранов проверен в Chromium, WebKit и Firefox на ширинах `320`, `375`, `414`, `768`, `1280`. На `320` дополнительно выполнена проверка при увеличении текста до `130%`.

| Движок | Обычный текст, 5 ширин | Текст 130%, 320 px | Результат |
|---|---:|---:|---|
| Chromium | 55/55 | 11/11 | PASS |
| WebKit | 55/55 | 11/11 | PASS |
| Firefox | 55/55 | 11/11 | PASS |
| **Всего** | **165/165** | **33/33** | **198/198 PASS** |

Проверка контролирует ширину документа и границы видимых элементов: горизонтального скролла и выхода контента за viewport нет. Полные кадры лежат в `matrix/<engine>/<width>/`.

Дополнительные функциональные проверки в `qa-results.json`: Enter переводит фокус на следующее поле, Enter не создаёт отправку, а рабочий экран приёмки содержит поле суммы и кнопку. Все три проверки — `true`.
