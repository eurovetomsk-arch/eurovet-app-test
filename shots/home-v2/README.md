# Главная 2.0 — контрольные снимки

Синтетические тестовые данные, без рабочих денег и персональных данных.

Роли: `admin`, `doctor`, `assistant`, `callcenter`, `aho` (Специалист АХО), `head`. Для каждой роли сохранены PNG на ширинах 375 и 320 точек: `<ширина>-<роль>.png`. Нижняя навигация на длинных снимках находится в потоке страницы и не перекрывает содержимое.

Вход:

- `375-entry-start.png` — стартовый экран;
- `375-entry-mark-closeup.png` — знак из утверждённого SVG-symbol крупно;
- `375-entry-number.png` — ввод личного номера;
- `375-entry-pin.png` — PIN и полноширинная клавиатура;
- `320-entry-longest-slogan.png` — длинный слоган без переноса на 320 точках.

Автоматическая проверка `tests/home-v2.test.cjs` дополнительно проходит эти шесть ролей на ширинах 320, 375, 414, 768 и 1280 в Chromium, Firefox и WebKit. Проверяются отсутствие горизонтального скролла, состав и порядок плиток, полная ширина одиночной плитки, фирменный знак, клавиатура, нижняя навигация, двойная роль и отсутствие будущих модулей на главной. `tests/slogans-3014.test.cjs` проверяет десять последовательных дат, точный список слоганов и отсутствие переноса на 320 точках.
