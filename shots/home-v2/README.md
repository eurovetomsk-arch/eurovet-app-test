# Главная 2.0 — контрольные снимки

Синтетические тестовые данные, без рабочих денег и персональных данных.

Роли: `admin`, `doctor`, `assistant`, `callcenter`, `aho` (Специалист АХО), `head`. Для каждой роли сохранены PNG на ширинах 375 и 320 точек: `<ширина>-<роль>.png`.

Автоматическая проверка `tests/home-v2.test.cjs` дополнительно проходит эти шесть ролей на ширинах 320, 375, 414, 768 и 1280 в Chromium, Firefox и WebKit. Проверяются отсутствие горизонтального скролла, состав плиток, нижняя навигация, двойная роль и отсутствие будущих модулей на главной.
